# Neuromicon Studio — отчёт по ревью функциональности, UX и совместимости

**Дата отчёта:** 18 ноября 2026, 05:40 UTC
**Версия:** `neuromicon-studio_1f27f2.zip` (≈15,4 тыс. строк TS/TSX; `App.tsx` 2963, `InspectorPanel.tsx` 2466, `TimelineDock.tsx` 1605)
**Цель продукта:** удобный и понятный редактор для создания музыкальных клипов (аудио-реактивные сцены, клипы, субтитры, экспорт).

## 1. Резюме

Продукт сильно вырос: есть undo/redo, автосохранение проекта в IndexedDB, субтитры SRT/VTT, оверлеи, FX-дорожка, бит-маркеры, привязка к битам, пакетный экспорт, горячие клавиши, русский и английский интерфейс. Сборка чистая.

Главные проблемы теперь не в отсутствии функций, а в **удобстве и предсказуемости**:

1. Таймлайн нарушает требование «элементы не перекрывают друг друга»: FX-клипы лежат на одной дорожке фиксированной высоты и накладываются друг на друга; всплывающие меню, вероятно, обрезаются контейнером прокрутки.
2. При увеличении масштаба плейхед уходит за экран, потому что нет автопрокрутки.
3. Рабочая область не учитывает реальные размеры экрана: центральная колонка с превью сжимается до ~400 px на ширине 1024 px.
4. Часть функций таймлайна не видна пользователю (субтитры и текстовые оверлеи редактируются только в боковой панели), а горячие клавиши конфликтуют с клавиатурной доступностью.
5. Возможность быстрой смены Outgoing Transition
6. Смена цвета для Visualizer для BeatFX в том числе возможность отключения. 

## 2. Критичные проблемы (P0)

### P0-1. FX-клипы перекрывают друг друга на таймлайне — **[Высокая]**
- `TimelineDock.tsx`, «Track 2: Generator FX Overlays Lane»: контейнер `h-8 relative`, каждый FX позиционируется `absolute` с `left/width` в процентах. Раскладки по дорожкам (lanes) нет, поэтому два FX с пересекающимся временем рисуются друг поверх друга. Выбранный получает `z-10`, остальные недоступны для выбора и перетаскивания.
- Левая колонка подписей жёстко задана (`h-4`, `h-11`, `h-8`, `h-8`, `h-5`), поэтому дорожка не может вырасти без рассинхронизации подписей.
- **Что сделать:** алгоритм раскладки по lane (greedy interval packing): сортировка по `startSec`, каждый FX кладётся в первую lane, где нет пересечения. Высота дорожки = число lane × 24 px, подписи слева строятся из тех же данных (единая модель строк таймлайна, см. P1-1). Запретить наложение при перетаскивании или автоматически переносить в новую lane.
- **Приёмка:** два FX с пересекающимися интервалами отображаются в разных lane, оба выбираются, перетаскиваются и меняют размер без визуального наложения.

### P0-2. Всплывающие меню на таймлайне, вероятно, обрезаются — **[Высокая по CSS, Проверить визуально]**
- Меню выбора перехода (`absolute bottom-full -translate-x-1/2 w-56`, ~200 px высотой) находится внутри контейнера `overflow-x-auto overflow-y-visible`. По спецификации CSS при `overflow-x: auto` значение `overflow-y: visible` вычисляется как `auto`. Меню обрезается или даёт вертикальную прокрутку внутри дорожки высотой ≈ 100 px.
- Кроме того, `-translate-x-1/2` по `left: %` выводит меню за левый или правый край при переходах у границ.
- **Что сделать:** рендерить меню через портал (`createPortal` в `document.body`) с позиционированием по `getBoundingClientRect()` кнопки и коррекцией по границам окна. Меню «Генераторы» и «Beat sync» (открываются вверх от панели) проверить так же.
- **Приёмка:** меню полностью видимо при переходе на первом и последнем клипе, при масштабе 1–8× и при прокрутке.

### P0-3. При масштабировании плейхед теряется — **[Высокая]**
- В `TimelineDock.tsx` нет ни одного `scrollLeft`/`scrollTo`/`scrollIntoView`. При масштабе >1× воспроизведение уходит за пределы видимой области, и пользователь не видит, где находится.
- Масштаб меняется только Ctrl/⌘+колесо, шагом 0,5, от левого края (а не от курсора или плейхеда). Кнопок «+ / −» и «Вписать всё» нет (только слайдер `timelineZoomLabel`). Горизонтальной прокрутки жестом/колесом без Ctrl тоже нет.
- **Что сделать:** режим «следовать за плейхедом» (по умолчанию вкл.) с автопрокруткой при выходе за 80% ширины; зум относительно курсора или плейхеда; кнопки «Вписать всё» и «К плейхеду»; горизонтальная прокрутка колесом/Shift+колесо.
- **Приёмка:** при зуме 8× воспроизведение всегда видно без ручной прокрутки.

### P0-4. Раскладка не защищает превью от сжатия — **[Высокая по классам, Проверить визуально]**
- `MediaInputPanel`: `lg:w-[300px] xl:w-[325px]`; `InspectorPanel`: `lg:w-[325px] xl:w-[360px]`; `PreviewStage`: `flex-1`. На 1024 px центральная колонка ≈ 400 px, на 1280 px ≈ 655 px. Тулбар превью (`flex-wrap`) и панель горячих клавиш (`absolute top-12 left-4 right-4 max-w-2xl` внутри `overflow-hidden`) обрезаются.
- Корневой контейнер `lg:h-screen lg:overflow-hidden`, а `TimelineDock` — `shrink-0` внизу. Её высота переменная (тулбар переносится на несколько строк + мастер-дорожка + 3–5 дорожек + подписи), поэтому на ноутбуках 720–800 px по высоте превью получает остаток. Минимальной высоты нет.
- **Что сделать:** сворачиваемые боковые панели (кнопки «скрыть левую/правую»), ресайз панелей перетаскиванием с запоминанием, `min-w` для превью, сворачиваемый таймлайн с ручкой высоты, проверка на 1024×720, 1280×720, 1440×900, 1920×1080. Панель горячих клавиш вынести в модальное окно (портал).
- **Приёмка:** на 1280×720 превью не меньше 640×360 при развёрнутом таймлайне; ни один элемент интерфейса не обрезается и не накладывается.

## 3. Важные проблемы (P1)

### P1-1. Таймлайн неполный и непоследовательный
- На таймлайне есть: клипы, FX, аудио с бит-сеткой, субтитры (только если они есть). **Текстовые и графические оверлеи на таймлайне не отображаются**, редактируются только в левой панели. Пользователю не очевидно, где и когда они показываются.
- **Что сделать:** единая модель дорожек `TimelineTrack[]` (клипы, FX, оверлеи, субтитры, аудио) с одинаковыми правилами выбора, перетаскивания, подрезки, lane-раскладки и подписей. Левая колонка подписей строится из этой модели, а не из зашитых высот.
- Длительность клипов на таймлайне должна настраиваться не зависимо от других ранее использованных клипов. Каждый клип независим от ранее использованного на таймлайне. 

### P1-2. Мастер-дорожка аудио: мелкие цели и лишний рендер — **[Высокая]**
- Ручки подрезки шириной `w-2` (8 px), высота дорожки `h-6` (24 px): на тач-экранах и для точного выбора неудобно (рекомендуемая цель ≥ 24–44 px).
- 220 DOM-элементов столбцов волны перерисовываются при каждом обновлении `currentTime` (порядка 60 раз в секунду) с пересчётом цвета «сыграно/нет». Рисовать волну на `<canvas>` или одним SVG-путём, а закраску проигранной части делать маской/градиентом.

### P1-3. Горячие клавиши конфликтуют с доступностью и нигде не подсказаны — **[Высокая]**
- Глобальный `keydown` (`App.tsx`, ~2490) перехватывает **Space, Delete, Backspace, стрелки** на всём окне, кроме `INPUT/TEXTAREA/SELECT`. Если фокус на кнопке или на `role="slider"`, Space не активирует кнопку (вызывается `preventDefault`), а стрелки двигают плейхед вместо ручки подрезки.
- Backspace/Delete удаляют выбранный клип без подтверждения; есть undo, но пользователь должен о нём знать.
- Подсказка «Клавиши» есть, скрыта за кнопкой в тулбаре превью.
- **Что сделать:** не перехватывать Space/Enter, когда фокус на `button`, `a`, `[role=slider]`, `[role=menu*]`; для слайдеров подрезки добавить `tabIndex=0` и стрелочное управление (`aria-valuemin/max/valuenow`); показывать подсказки горячих клавиш в `title` кнопок и добавить тост «Удалено — Ctrl+Z, чтобы вернуть».

### P1-4. Начальный сценарий (онбординг) не ведёт пользователя
- Есть пустое состояние (`emptyStageTitle`), но нет пошагового сценария «1. Добавьте трек → 2. Добавьте клипы → 3. Выберите стиль → 4. Экспорт».
- **Что сделать:** чек-лист из 4 шагов в пустом состоянии, подсветка следующего шага, «Демо-бит» как быстрый старт, кнопка «Экспорт» с готовыми пресетами по площадкам (YouTube 16:9, Shorts/Reels/TikTok 9:16, Instagram 1:1) и предупреждением, если нет аудио или клипов.

### P1-5. Нестабильное визуальное поведение при плотных подписях
- Колонка подписей `w-12` (48 px) с `truncate` даёт обрезанные локализованные названия («Дорожка клипов», «Субтитры»). Кнопки −0,5 s/+0,5 s имеют не локализованные `aria-label="-0.5s"`.
- Строка 1 тулбара таймлайна с `flex-wrap` растёт на 2–3 строки на узких экранах и «съедает» высоту превью. Сгруппировать действия: основная панель + меню «Ещё».
- при укорачивании слипа на таймлайне возможность подстраивать клип на таймлайне к биту
- При выборе клипа на таймлане и изменении его времени то изменять должен только выбранный на тайлайне клип а не все его копии.

## 4. Технические проблемы и совместимость (P1–P2)

## 5. Что сделано хорошо (сохранить)

- Undo/redo с debounce-группировкой правок и снимками конфигурации и клипов.
- Автосохранение проекта и восстановление медиа из IndexedDB.
- Привязка к битам (snap), бит-маркеры (двойной клик по аудио-дорожке), автоматическая раскладка по битам.
- Трассировка пользовательских ошибок через тост (`showError`).
- Двуязычный интерфейс (RU/EN), `prefers-reduced-motion`.
- Проверка поддержки кодеков до экспорта и запасной путь.
